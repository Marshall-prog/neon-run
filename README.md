# NEON RUN

**Играть в браузере:** https://marshall-prog.github.io/neon-run/

NEON RUN — преодолевай препятствия, собирай монеты, устанавливай рекорды.

## Управление

**Телефон**
- тап — прыжок
- второй тап в воздухе — двойной прыжок
- свайп вниз — присед / быстрое падение
- кнопка ⏸ — пауза

**Компьютер**
- `↑` / пробел — прыжок (повторно — двойной)
- `↓` — присед
- `Esc` — пауза

Музыка и звук включаются/выключаются отдельно, выбор сохраняется.
